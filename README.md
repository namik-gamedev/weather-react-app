# Weather React App

Приложение прогноза погоды на React. Показывает погоду по выбранному местоположению и запоминает его.

**Демо:** https://gnamik-weather.vercel.app

## Возможности
- Поиск города
- Текущая температура, ощущаемая температура, ветер, влажность
- Состояния загрузки и ошибки

## Стек
- React
- OpenWeatherMap
- CSS Modules
- Create React App
- Vercel

## Запуск
```bash
git clone https://github.com/namik-gamedev/weather-react-app.git
cd weather-react-app
npm install
npm start
```
Приложение откроется на http://localhost:3000.

Создайте файл `.env` в корне проекта и добавьте ключ:
```
REACT_APP_API_KEY=ваш_ключ
```
